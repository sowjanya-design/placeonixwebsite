Introduction

What you learn in this Full Stack course

Full stack developers who can work confidently across the front end, back end and database layer are consistently among the most sought-after hires in software teams of every size, from early-stage startups to large enterprises.

This course takes you from web fundamentals to building and deploying complete applications. You will master HTML/CSS/JavaScript and responsive design, build modern interfaces with React, create REST APIs with Node.js and Express, work with MongoDB and SQL databases, add authentication, and deploy your applications live — using Git/GitHub as your daily workflow throughout. Every concept is reinforced with coding practice so you leave with a deployed, portfolio-ready capstone project.

Curriculum

Detailed Full Stack curriculum

Structured modules that build from web fundamentals to a complete, deployed application.

Week 1 HTML, CSS & JavaScript Fundamentals
  • Semantic HTML5 and modern CSS3 (Flexbox, Grid)
  • JavaScript fundamentals — DOM, events, ES6+ syntax
  • Responsive design and mobile-first layouts
Week 2 React for the Front End
  • Components, props and state
  • Hooks (useState, useEffect, custom hooks)
  • Routing and state management basics
Week 3 Node.js & Express
  • Node.js runtime fundamentals and npm
  • Building REST APIs with Express
  • Middleware, error handling and project structure
Week 4 Databases — MongoDB & SQL
  • MongoDB schema design and Mongoose
  • Relational database fundamentals with MySQL
  • CRUD operations and query design
Week 5 Authentication & API Design
  • REST API design principles and versioning
  • Authentication with JWT and sessions
  • Authorization and protecting routes
Week 6 Git, Deployment & Hosting
  • Git/GitHub workflow — branching, PRs, collaboration
  • Deploying front-end and back-end apps to hosting platforms
  • Environment variables and production configuration
Week 7 Capstone Project
  • End-to-end full stack application build
  • Code review, testing basics and refinement
  • Deployment and portfolio presentation
