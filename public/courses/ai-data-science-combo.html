Introduction

What you learn in this combo

Analytics and AI roles increasingly overlap — data scientists are expected to understand generative AI, and AI practitioners need strong data fundamentals. This combo starts with Python, statistics, exploratory data analysis and SQL, moves through classical machine learning (regression, classification), then introduces generative AI concepts — LLMs, prompt engineering and responsible AI — plus practical use cases like chatbots and document analysis.

Three mini-projects and a full capstone (data pipeline, model/prototype, AI integration, dashboard/report) give you portfolio-ready, demonstrable work across both disciplines.

Curriculum

Detailed AI + Data Science curriculum

24 weeks combining Data Science foundations with Generative AI, each module labelled by sub-course focus.

Week 1-2 Data Science Foundations Python, Statistics & EDA
  • Python recap, Pandas and Numpy, data cleaning
  • Statistics basics, exploratory data analysis and visualization
Week 3-4 Data Science SQL, Dashboards & ML Foundation
  • SQL analytics queries, dashboard basics, Power BI overview
  • ML workflow, regression/classification overview, evaluation metrics, first model
Week 5 Data Science Advanced ML Basics
  • Feature engineering, model comparison, cross-validation, hands-on tuning
Week 6-7 Generative AI Foundation & Use Cases
  • LLM concepts, prompt engineering, GenAI tools, responsible AI
  • Chatbots, document analysis and AI for business workflows
Week 8 Generative AI Python AI Libraries
  • Working with APIs, embeddings overview, vector search concept, hands-on demo
Week 9-11 Mini Projects
  • Analytics dashboard project
  • ML model project with evaluation and reporting
  • Generative AI mini application with prompt workflow
Week 12-13 Business Case Study & Deployment
  • Problem definition, data selection, model/AI approach and presentation
  • Model/API deployment basics, environment variables, cloud hosting overview
Week 14-17 Capstone Project
  • Capstone planning: architecture and milestones
  • Data pipeline and model/prototype build

Week 18-24 Interview & Placement Readiness
