Introduction

What you learn in the flagship program

Most SAP developers specialise in one layer of the stack. This program is built to take you across all of them: SAP BTP and HANA Cloud as the foundation, the Cloud Application Programming (CAP) model for backend services, SAP UI5/Fiori for the front end, and SAP CPI for connecting SAP and non-SAP systems — plus the security (XSUAA) and deployment practices that tie it all together.

You build three mini-projects across the CAP backend, the UI5/Fiori front end and a CPI integration flow, then combine everything into a full capstone application — designed, built, secured, integrated and deployed end to end, giving you the strongest possible portfolio for SAP full stack developer roles.

Curriculum

Detailed SAP Full Stack Program curriculum

24 weeks spanning SAP BTP, CAPM, UI5/Fiori and CPI, each module labelled by sub-course focus, ending in a full capstone build.

Week 1-2 SAP BTP Foundation & HANA Cloud
  • SAP ecosystem overview, BTP architecture, accounts and subaccounts
  • HANA Cloud concepts, HDI containers and database explorer
Week 3-4 SAP CAPM Development
  • CAP architecture, Node.js CAP project, CDS modelling
  • Service handlers, validations and OData exposure
Week 5-6 SAP UI5/Fiori Development
  • UI5 MVC, views, controllers and models
  • Routing, fragments and Fiori UX
Week 7-8 SAP CPI Integration
  • Integration Suite, IFlow basics and adapters
  • Mapping, Groovy basics and monitoring
Week 9-10 Security & Full-Stack Integration
  • XSUAA, role collections and authentication flow
  • UI5 consuming CAP services, OData integration and error handling
Week 11-12 External Integration & Deployment
  • Destinations, REST/OData APIs and connectivity patterns
  • MTA deployment, service binding, logs and troubleshooting
Week 13-16 Mini Projects
  • CAP backend project (database + services)
  • UI5/Fiori frontend project (routing + OData)
  • CPI integration scenario (monitoring + error handling)
Week 17-21 Capstone Project
  • End-to-end architecture design and business use case selection
  • CAP backend, HANA model and security setup
  • UI5/Fiori frontend and API integration
  • CPI integration, deployment, monitoring and documentation
Week 22-24 Interview & Placement Readiness
  • BTP/CAPM interview questions and project walkthrough
  • UI5/CPI scenario-based interview questions
  • Resume, LinkedIn, GitHub notes and mock interviews
