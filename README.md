# Placeonix — website

SAP/IT training-institute marketing site. Built with **Next.js 16 (App
Router) + TypeScript**, living entirely under `web-next/`. There is no other
active codebase in this repo — everything at the repo root besides
`web-next/` is just top-level config.

## Repo root

```
.env.example   Template for the SMTP env vars the application-form API
               route needs (SMTP_HOST/PORT/SECURE/USER/PASS, ADMIN_EMAILS).
               Copy to web-next/.env.local and fill in real values.
.gitignore     Root-level ignore rules (node_modules, .next, etc.)
README.md      This file.
web-next/      The entire Next.js application — see below.
```

## `web-next/src/app/` — routes (Next.js App Router)

Each folder under `app/` is a URL route; `page.tsx` is what renders there.

```
layout.tsx        Root layout for every page: <html>/<body>, Inter font,
                   default SEO metadata (title/description/OG/Twitter),
                   the sitewide EducationalOrganization JSON-LD block, the
                   scroll-reveal observer, and the global LeadPopup (so the
                   30-second lead-capture modal appears on every page, not
                   just the homepage).
page.tsx           Homepage — hero, features, program cards, "how it
                   works", journey section, internship tracks panel,
                   certificate showcase, hiring-partner logo marquee,
                   trust stats, admissions form, FAQ.
globals.css        Shared design system (colors, buttons, nav, cards, forms,
                   legal-page prose styles, internship/certificate
                   sections). Loaded on every page via layout.tsx.
home.css           Homepage-only styles, imported additionally by page.tsx.
                   Has its own :root color overrides (indigo/violet theme)
                   that take precedence over globals.css on the homepage.
icon.png           512×512 square app icon — Next's file-based favicon
                   convention auto-serves this at /icon.png.
robots.ts           Generates /robots.txt — allows all crawling except
                   /api/, points to the sitemap.
sitemap.ts          Generates /sitemap.xml — every static route plus every
                   course/category page, pulled from lib/courses.ts so it
                   can't drift out of sync with the actual course list.

api/applications/route.ts   POST route handler for every enquiry/lead form
                   on the site (homepage admissions form + the global lead
                   popup). Sends admin + student emails via nodemailer
                   using the SMTP_* env vars.

courses/page.tsx                        "All Courses" hub (/courses).
courses/[category]/page.tsx             Category hub — /courses/sap,
                   /courses/technology, /courses/combo.
courses/[category]/[slug]/page.tsx      The course detail template — one
                   file renders all 22 course pages via
                   generateStaticParams, driven entirely by
                   data/courses.json. Includes full JSON-LD
                   (Course/FAQPage/BreadcrumbList).

internships/page.tsx   The /internships hub: hero, live search + category
                   + availability filters, track list, "what to expect",
                   who-can-apply / process / FAQ panels. Data comes from
                   lib/internships.ts (single source shared with the
                   homepage panel).

privacy-policy/page.tsx   Full Privacy Policy (real legal text, not a
                   placeholder) rendered through the shared LegalPage
                   component.
terms/page.tsx            Full Terms and Conditions, same pattern.
```

## `web-next/src/data/` and `web-next/src/lib/`

```
data/courses.json   Every course's full content (meta tags, hero, curriculum
                     modules, careers table, tools, projects, eligibility,
                     cert/placement cards, related links, FAQ) — extracted
                     once from the original static HTML, now hand-edited
                     directly when course content changes.
data/home.json       Homepage content blocks (hero, features, vis cards,
                     process steps, internship copy, FAQ).
data/nav.ts          Shared nav link arrays (sapLinks/technologyLinks/
                     comboLinks) used by both MegaNav and SideNav.

lib/courses.ts       Data-access layer over courses.json: getAllCourses(),
                     getCoursesByCategory(), getCourse(), 
                     getAllCourseParams() (feeds generateStaticParams AND
                     the sitemap), categoryLabels.
lib/internships.ts    Single source of truth for the 6 internship tracks
                     (name, category, tags, description, eligibility,
                     duration, mode, status, apply-by date) — imported by
                     both the homepage panel and the /internships page so
                     they can never show different data.
lib/types.ts          Shared TypeScript types (Course, FaqItem,
                     CurriculumModule, etc.) matching courses.json's shape.
```

## Setup

1. `cd web-next && npm install`
2. Copy the root `.env.example` to `web-next/.env.local` and fill in real
   SMTP credentials — the application form and lead popup can't send email
   without these. `.env.local` is gitignored; never commit real credentials
   into `.env.example`.
3. `npm run dev` → open `http://localhost:3000`

## Deploying

Deployed on Vercel, pointed at `web-next/` as the project root. Set the
same `SMTP_*` + `ADMIN_EMAILS` env vars in the Vercel project settings —
`src/app/api/applications/route.ts` is the Next.js Route Handler that
replaces what would otherwise be a separate Express/serverless function.

## Where to look first

- New to this project? Read `web-next/PROJECT_BRAIN.md` — it has the full
  history of design decisions, past bugs, and standing conventions.
- Changing course content → edit `web-next/src/data/courses.json` directly.
- Changing homepage content → `web-next/src/data/home.json` for
  data-driven sections, or `web-next/src/app/page.tsx` directly for
  hardcoded ones (trust stats numbers, partner logos).
- Nav/routing → `web-next/src/data/nav.ts` plus `MegaNav.tsx`/`SideNav.tsx`.
- Styling → `globals.css` (shared, all non-homepage pages) vs `home.css`
  (homepage-only overrides).
