# Curriculum Infographic Prompts — all 22 Placeonix courses

Ready to paste into any AI image generator (Higgsfield/nano_banana_pro, Midjourney,
DALL-E, etc.) once credits/access are available. Each prompt is self-contained and
uses the SAME real curriculum data already live in the coded `.glance` visuals on
the site, so the generated images will match what's already on the pages — just
render it as an actual graphic instead of/alongside the HTML version.

## Shared style brief (paste before every individual prompt, or fold it in)

```
Style: clean modern SaaS / ed-tech infographic. White or very light background.
Indigo brand gradient accents (#4f46e5 → #3730a3). Minimal flat line icons only
(no photorealistic people, no stock-photo imagery, no clutter). Sans-serif
typography (Inter/Helvetica style), crisp and highly readable at small sizes.
Generous white space. Professional, premium, trustworthy feel — like a modern
tech company's product page, not a school poster. Aspect ratio 16:9. High
resolution, sharp text rendering.
```

compressed) matching the filenames below — this is exactly what
`docs/curriculum-glance-pending-pages.md` and the site's `<img>` tags expect.
