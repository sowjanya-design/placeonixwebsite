# Design assets

Original/source logo files kept for reference — the site itself uses the
optimized, purpose-built versions in `public/` and `public/assets/img/`
(`public/logo.jpeg`, `public/favicon.jpeg`, `public/assets/img/logo-transparent.png`,
`public/assets/img/logo-white.png`). Nothing here is loaded by the running site.

| File | What it is |
|---|---|
| `logo-original.jpeg` | The original, pre-optimization logo file (75KB, 1600×586) before it was resized/compressed down to `public/logo.jpeg`. |
| `favicon-source.jpeg` | The source image used to generate `public/favicon.jpeg` (the browser tab icon / apple-touch-icon). |
