For EACH width above, on EACH of these pages: homepage (public/index.html),

3. TOUCH TARGETS - are all buttons/links at least 44x44px tappable area on

7. STICKY ELEMENTS - the site has a .sticky-cta (mobile-only bottom bar) and a
   .wa-float WhatsApp button (if added) - do they overlap each other or cover
   important content (like a "Submit" button) on short mobile screens?
8. SPACING - is padding/margin so large on mobile that content feels sparse,
   or so tight that sections run together? Compare against the existing 900px/
   768px/560px breakpoint values already in site.css as the baseline "feel".
